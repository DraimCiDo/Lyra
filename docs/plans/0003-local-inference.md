# M2 — локальный inference

Статус: в работе. Исходная ветка `feat/local-cli`; работа — `feat/local-inference`.

Подключить встроенный llama.cpp через безопасную Rust-обёртку, без HTTP,
отдельного сервера, API-ключа и автоматического скачивания весов.
Добавить `generate` с явным GGUF, prompt, контекстом, числом потоков,
GPU layers, лимитом ответа и времени. CPU — исходная сборка; CUDA — явный
feature, не скрытый fallback. Отмена по Ctrl+C и проверки до загрузки весов.
Не включать shell/tool calls и изменение файлов проекта.

Модель пользователя и RTX/CUDA недоступны. Маленькая тестовая модель проверяет
только механизм генерации, не качество кодинга и не производительность 7B.
Числа RAM/VRAM не являются жёсткой sandbox-квотой: явный контекст ограничивает
KV-cache, но выделения native runtime могут закончиться OOM. Не обещать гарантированное
восстановление после OOM ОС. Таймаут проверяется между native операциями.
