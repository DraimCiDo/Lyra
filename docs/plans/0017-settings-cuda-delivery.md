# Понятные настройки и GPU-поставка

Статус: в работе. База a719f4e, PR #4.

Поручение: продолжить программу, сделать настройки понятнее и поставлять
GPU-сборку вместе с CPU. В этом инкременте приоритет — интерфейс настроек
и завершённая native GPU-приёмка; rules/scopes остаются следующим блоком.

Изменения: подписанная адаптивная навигация, навыки отдельно от агентов,
пояснения разделов, GPU/CPU рядом с выбранной моделью, продвинутые параметры
свернуты. CUDA-новый профиль по умолчанию Auto; явный сохранённый CPU сохраняется.
CPU-сборка не предлагает недоступное ускорение. Настройки обновлений правильно
показывают тип сборки; CUDA updater не подменяется CPU-пакетом.

GPU workflow: отдельный ограниченный native cache с ключом CUDA/arch/toolchain/
зависимостей, notices и SHA256 для EXE/DLL в portable пакете. CPU workflow сохраняется.
Cache повторяет существующий подход CPU CI; полный target не кешируется.

Критерии:

- [ ] Все разделы достижимы с подписями на 820×600 и 1160×760, RU/EN.
- [ ] Smoke перебирает все реальные страницы, а не первые семь.
- [ ] GPU defaults/reset и сохранённый CPU проверены регрессией.
- [ ] Windows/Linux CI и CUDA build текущего кода прошли.
- [ ] Оба пакета скачаны/проверены; GPU inference на RTX 4060 действительно offload.
- [ ] Сопоставимый CPU/GPU замер одной модели/контекста/запроса с точными
  параметрами, временем и ограничениями; не обещать ускорение без результата.

Локально Cargo/MSVC нет: сборка в CI, native acceptance — скачанными EXE.
