# M1 — локальный Rust CLI и сборка Windows

Статус: в работе. Ветка `feat/local-cli`, исходная ревизия `c5d1b52`.

## Задача и изменение требований

Начать реализацию CLI и сборки Windows. Пользователь подтвердил, что Windows
локально недоступна: выполнять доступные проверки, не подменять ими Windows-приёмку.
Новое требование: работа AI на ресурсах ПК, без обязательного облачного сервиса.
Прежний план OpenAI-first заменяется локальным inference-first.

Профиль ПК получен от пользователя; VRAM уточнена до 8 ГБ. Полный профиль
сохранён только локально в игнорируемой `.lyra/user-hardware.json`.
Свободное место на SSD и версия Windows неизвестны; результаты inference
не измерялись. Параметры облачного исполнителя не считаются параметрами ПК пользователя.

## Границы

M1 создаёт CLI `--help`, `--version`, `doctor` и JSON-отчёт о локальном железе,
Cargo-проект, закреплённый Rust, тесты и CI Linux/Windows с артефактом EXE.
Диагностика не отправляет данные и не запускает shell/команды из модели.
Веса LLM, генерация, редактирование кода и sandbox относятся к следующим этапам.

Зависимости: `clap` для корректного CLI, `sysinfo` для переносимой диагностики
без собственного unsafe/PowerShell, `serde`/`serde_json` для машинного отчёта.
Включить только нужные features, не собирать процессы, пользователей и сеть.
Версии сверить с registry/docs, зафиксировать `Cargo.lock`.
