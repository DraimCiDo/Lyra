## Отдельная находка реальной кодинг-приёмки

На изолированной Python-фикстуре с CRLF две реальные GGUF не завершили
полный цикл task → apply → успешный тест. 7B предложила правильную правку,
но повторяла предложение и дошла до step_limit; 9B читала оба файла, но её
точные замены были отклонены, затем закончился бюджет шагов. Незавершённый
отчёт корректно отклонён apply, файл не изменён. Причина несовпадения old
без сырых отклонённых действий не установлена; CRLF сам по себе не доказан.
Это отдельный открытый вопрос качества/протокола реальных моделей, а не
успешная кодинг-приёмка. Детерминированные CI fixtures и чат-smoke его не заменяют.
