# Чат вместо мастера проекта; веб-контекст

Статус: в работе. main, исходная ревизия f4f29f9.

Пользователь попросил поддержку современного оформления веб-проектов (Vue/TS),
показать приложение, затем явно заменить отдельный мастер новым интерфейсом чата:
промпт и необязательный выбор существующего проекта.

## План и границы

- Единый чат: сообщения, composer снизу, необязательная папка проекта,
  выбранная локальная GGUF. Без папки используется project planner.
- Уточнения/результат видны в чате; код и применение остаются явными.
  После AI blueprint пользователь выбирает место и создаёт новую папку.
  Отдельного окна/формы «Новый проект» больше нет; CLI-каркасы сохраняются.
- Ограниченная история только в RAM; сброс при смене проекта, без автоматической
  записи и неограниченного роста контекста. Ошибки/отмена не теряют введённый текст.
- Профиль Vue/TypeScript и официальные источники; без установки web runtime
  в поставку Lyra и без обещания качества Astra по одному профилю.
- Native компактность, RU/EN, темы, worker cancellation, path guards и updater
  сохраняются. Никакого произвольного исполнения кода модели.

## Источники

Официальные Vue TypeScript overview и Vite guide прочитаны через HTTPS:
https://vuejs.org/guide/typescript/overview.html и https://vite.dev/guide/.
Vue рекомендует create-vue/Vite; Vite transpilation не заменяет type-checking,
для SFC нужен vue-tsc. Версии npm-пакетов не выдумываются и не фиксируются
без источников. UI-профиль — рекомендации модели, не гарантия дизайна.

## Реализация и локальные проверки

`src/desktop/chat.rs`: ограниченная история и prompt-first home; старый wizard
удалён, `projects.rs` хранит только draft, обработку worker и inline preview.
Разрешения/таймауты/отмена/отдельное применение сохранены. Передача файлового кода
модели по-прежнему ограничена движком; история не сохраняется в preferences.
Пределы: 32 сообщения / 256 KiB RAM-текста / 16 KiB request; реальные token limits
GGUF проверяются отдельно. Смена проекта очищает контекст, отчёт и предложения.

Vue/TypeScript: CLI/serde `vue-typescript`, native grammar, справочники Vue/Vite/TS,
manifest-based detection и import ts/vue/css. Новых Rust/npm зависимостей нет;
23 встроенных Lucide из прежней pinned-ревизии, два новых SVG без изменения лицензий.
Vue-каркас не добавлялся: это профиль AI-плана, а TypeScript CLI starter остаётся Node.

Debian 13 / Rust 1.99.1: 76 ordinary tests прошли; Clippy all-targets desktop
с `-D warnings`; явные native GGUF/grammar 2/2. После сохранения журнала событий
повторены 26 library/UI tests. Headless layout покрывает 4 темы × 2 языка ×
9 экранов × 2 размера (760×480/640×460). Native Xvfb/Mesa smoke прошёл все
72 состояния без чтения/записи пользовательских preferences.

Реальный оконный тест: GGUF Qwen2.5-Coder 0.5B Q4, локальный CPU, ввод и Enter
через X11; наблюдался отдельный worker, получен ответ/blueprint с main.py и
print('Hello, Lyra!'). Создание не нажималось, файлов проекта не записано.
Ошибку фокуса в Xvfb-драйвере исправили явным windowfocus до набора; это не
дефект приложения. [Главное окно](../images/desktop.png),
[переписка](../images/chat.png) и настройки сняты с реального приложения Linux.
