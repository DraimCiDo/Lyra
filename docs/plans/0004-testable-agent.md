# Тестируемая alpha: проект, инструменты и подагенты

Статус: тестируемая alpha реализована; качество целевой 7B/CUDA и автономный shell не приняты. Исходная ревизия `2e17769`, ветка `feat/testable-agent`.

Поручение: подготовить программу к полноценному тестированию, добавить основу
подагентов и повысить эффективность; другие языки допустимы при обоснованной пользе.

## Результат и границы

`task`: ограниченный цикл типизированных JSON-действий, контекст проекта,
чтение/поиск, предложения точных изменений и итоговый отчёт. Подагенты
исследования/ревью — опциональны, read-only, без рекурсивного делегирования,
с общим бюджетом и одной загрузкой модели. Последовательное исполнение по умолчанию.
`apply`: отдельное явное применение одного предложения с проверкой исходного
содержимого, без исполнения текста модели как команды. Изменения исходников
не применяются автоматически. Команды shell отсутствуют до OS sandbox.

Тестируемая alpha не означает завершённый M4 или подтверждённое качество 7B/CUDA.
Rust — CLI/политика/оркестратор, C/C++ — inference, Python — инфраструктура CI.
Не добавлять другой runtime в поставку без измеримого выигрыша.

## Критерии приёмки

- [x] Одна модель загружается один раз; отдельный контекст каждой роли.
- [x] Бюджеты шагов, делегирования, чтения, вывода, контекста и общего времени.
- [x] Проектные данные не расширяют права; секреты/служебные файлы исключаются.
- [x] Обход путей и symlink/junction не дают доступа за корень проекта.
- [x] Предложение правки проверяется; конфликт не перезаписывает пользовательский файл.
- [x] Детерминированные сквозные тесты через fake backend: задача → чтение →
  предложение → ревью → отчёт → применение → известная проверка результата.
- [x] Отдельный native smoke с маленьким GGUF проверяет повторные запросы
  одной модели; не выдаётся за качество кодинга.
- [x] Windows/Linux CI, инструкции приёмки и результаты; commit/push.

## Открытые ограничения

Shell sandbox/CUDA/качество Qwen на пользовательском ПК не проверены.
Одновременное изменение файлов внешними редакторами требует отдельной проверки;
перед применением исходный файл сравнивается повторно. Multi-file транзакция
не заявляется: применяется одно явно выбранное предложение за команду.

## Проверки и фактические ограничения

Linux: Rust 1.99.1, release; обычные проверки — 6 модульных, 9 agent integration,
6 CLI и 3 inference (24), отдельно 2 native smoke с локальным GGUF. fmt/Clippy
проходят. Native smoke проверяет одну загрузку/независимые контексты, system/raw
подачу, GBNF и enum путей, не качество кодинга.

Сквозной детерминированный тест использует заданные ответы backend: реальный
Rust-тест падает до правки, проходит после отдельного CLI apply; сохранены
проверки/CRLF. Это не доказательство принятия решения языковой моделью.
Проверены конфликты, неоднозначные замены, read-only, секретные пути/gitignore,
вложенные исключения, symlink в Linux и junction в Windows CI.

Обнаружен и исправлен native abort: sample() уже принимает токен; повторный
accept() ломал grammar state. Добавлена реальная регрессионная проверка sampler.
Веса загружаются один раз за task, роли последовательны, контексты раздельные.
CPU threads по умолчанию — min(8, доступный параллелизм), с учётом квоты среды.

## Предварительная проверка instruction-модели: отрицательный результат

Отдельно, вне обычного CI, загружен официальный Qwen2.5-Coder-0.5B-Instruct
Q4_K_M: revision ebb2015119c907b064c512bf053e945850b5875f, 491400064 байт,
Apache-2.0. Веса/транскрипты не входят в Git и поставку.
Первый прогон завершил протокол без правок — это не исправление задачи.
После выделения system message модель повторяла недопустимый пример пути;
получила отказы, затем timeout (exit 124). Пути затем ограничены enum в GBNF.
Последний прогон: 2 CPU threads, context 4096, max-tokens 256, max-calls 6,
общий timeout 180 s — около 34,84 s, 6 отклонённых замен, 0 предложений,
step_limit/exit 1. Качество кодинг-сценария этой моделью **не принято**.
Контроллер отказал неверным действиям и не менял исходники.
Целевая 7B на ПК пользователя не проверялась; улучшение схемы не выдаётся за
доказанное улучшение качества модели.

## Ресурсы и воспроизводимость

Облачная среда: Debian 13 x86_64, Xeon Platinum 8573C, cgroup 2 CPU.
Это не пользовательский 5700X/RTX 4060. Native release собран с -O3, AVX/AVX2,
без target-cpu=native. Бинарник alpha около 9,16 MB против 7,24 MB до оркестратора.
20 чередующихся пар generate (одинаковый tiny GGUF, 4 токена, context 128,
2 threads): до медиана 8,383 ms (7,690–15,304), после 8,374 ms (7,996–10,865).
Вывод greedy совпадает. Диапазоны пересекаются; это не замер 7B/Windows/GPU
и не основание обещать ускорение подагентами. Более поздний auto-thread default
дополнительно проверяется CI; для замера threads были заданы явно.

Приёмка на целевой модели/ПК: docs/ACCEPTANCE.md. Полный M4, произвольный shell,
создание/удаление файлов, параллельный inference, гарантии ACL/owner/сбойного
восстановления и multi-file транзакции в этой alpha не реализованы.
