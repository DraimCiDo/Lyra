# Тестируемая alpha: проект, инструменты и подагенты

Статус: в работе. Исходная ревизия `2e17769`, ветка `feat/testable-agent`.

Поручение: подготовить программу к полноценному тестированию, добавить основу
подагентов и повысить эффективность; другие языки допустимы при обоснованной пользе.

## Результат и границы

`task`: ограниченный цикл типизированных JSON-действий, контекст проекта,
чтение/поиск, предложения точных изменений и итоговый отчёт. Подагенты
исследования/ревью — опциональны, read-only, без рекурсивного делегирования,
с общим бюджетом и одной загрузкой модели. Последовательное исполнение по умолчанию.
`apply`: отдельное явное применение одного предложения с проверкой исходного
содержимого, без исполнения текста модели как команды. Изменения исходников
не применяются автоматически. Команды shell отсутствуют до OS sandbox.

Тестируемая alpha не означает завершённый M4 или подтверждённое качество 7B/CUDA.
Rust — CLI/политика/оркестратор, C/C++ — inference, Python — инфраструктура CI.
Не добавлять другой runtime в поставку без измеримого выигрыша.

## Критерии приёмки

- [ ] Одна модель загружается один раз; отдельный контекст каждой роли.
- [ ] Бюджеты шагов, делегирования, чтения, вывода, контекста и общего времени.
- [ ] Проектные данные не расширяют права; секреты/служебные файлы исключаются.
- [ ] Обход путей и symlink/junction не дают доступа за корень проекта.
- [ ] Предложение правки проверяется; конфликт не перезаписывает пользовательский файл.
- [ ] Детерминированные сквозные тесты через fake backend: задача → чтение →
  предложение → ревью → отчёт → применение → известная проверка результата.
- [ ] Отдельный native smoke с маленьким GGUF проверяет повторные запросы
  одной модели; не выдаётся за качество кодинга.
- [ ] Windows/Linux CI, инструкции приёмки и результаты; commit/push.

## Открытые ограничения

Shell sandbox/CUDA/качество Qwen на пользовательском ПК не проверены.
Одновременное изменение файлов внешними редакторами требует отдельной проверки;
перед применением исходный файл сравнивается повторно. Multi-file транзакция
не заявляется: применяется одно явно выбранное предложение за команду.
