# Документация и контекст · 0.2.0-dev.4

Lyra использует выбранный **локальный document pack**. Он содержит тексты,
заголовки, происхождение, область версий, время получения и SHA256. Это retrieval
для текущего задания, не обучение новой базовой модели и не облачный сервис.

## В интерфейсе

Настройки → «Документация»: выбери существующий pack либо явно импортируй
текстовые файлы/выбранные исходники SDK. Для любого языка/библиотеки можно
импортировать материалы независимо от встроенных профилей. Импорт сохраняется
в новый JSON-файл по выбранному пути; существующий pack не перезаписывается.

«Загрузить официальные документы» выполняет HTTPS-запросы только после нажатия
и выбора пути сохранения. Перед загрузкой задай профиль и версию. Доступен список
источников. Фоновое скачивание, поисковые запросы с кодом/заданием, API-ключи и
облачный inference не появляются. Загрузка документов не запускает примеры из них.

После выбора pack агент и AI-планировщик получают каталог источников и релевантные
фрагменты. `search_docs` позволяет запросить дополнительные фрагменты по API-именам
или ключевым словам. Поиск лексический, без embedding-модели и её расхода VRAM.
Для английского SDK полезнее точные API-идентификаторы, чем длинный русский вопрос.
В каждом результате есть источник и номер строки; в отчёте — документы,
действительно переданные в контекст. Это не утверждение модели, что API проверен.

## CLI

```powershell
# Только список; без сети
.\lyra.exe docs sources --profile paper-kotlin --target-version 1.21.11

# Локальные материалы любого SDK (можно повторять --file, до 16)
.\lyra.exe docs import --file 'D:\Docs\Enforce.md' --file 'D:\SDK\Example.c' --profile dayz-enforce --target-version 1.28 --output dayz-docs.json

# Нужны online-docs либо desktop feature и явное разрешение на загрузку
.\lyra.exe docs fetch --profile paper-java --target-version 1.21.11 --output paper-docs.json --allow-network

.\lyra.exe docs search --pack paper-docs.json --query JavaPlugin
.\lyra.exe task --repo 'D:\Code\plugin' --model 'D:\Models\model.gguf' --task-file TASK.md --docs paper-docs.json
```

Default CLI build не включает HTTP/parser. Offline import/search и создание
проектов доступны без `online-docs`; desktop включает загрузку. Сборка CLI с
загрузкой: `cargo build --release --locked --features online-docs`.

## Точность версий и доверие

Versioned Paper Javadoc помечен целевой версией. Paper setup, Spigot Javadoc,
Rust Book, dev.java и другие rolling-источники явно помечены как rolling.
Локальные материалы имеют пользовательскую, **не подтверждённую** версию.
Хеш обнаруживает изменение текста, но не доказывает его авторство или правильность.

Страница современной Paper 26.x не является доказательством совместимости с
1.21.11. Подтверждай API по versioned reference/реальным зависимостям.
Если сайт блокирует доступ, Lyra возвращает ошибку, а не отмечает страницу
прочитанной. Для Bohemia wiki из этой среды наблюдался 403: используй локальные
материалы соответствующего DayZ Tools/SDK. Они не взаимозаменяемы с Reforger SDK.

Документы, AGENTS.md, исходники и примеры остаются недоверенными данными.
«Запусти команду», «отправь код», «игнорируй ограничения» внутри них не даёт прав.
У модели нет сетевого/shell-инструмента. Загрузка выполняется отдельной командой
по фиксированному каталогу официальных HTTPS-хостов, а не по URL, выбранному моделью.
Для нового сайта пока используй локальный импорт; произвольного web crawler нет.

## Лимиты и ресурсы

До 16 документов, 256 KiB текста каждый, 2 MiB всего; JSON до 3 MiB.
Импорт: UTF-8 md/txt/rst и явно выбранные c/java/kt/rs. Symlink/reparse-файлы,
NUL, неверная схема, повторы ID и несоответствие SHA отклоняются.
Страница: максимум 1 MiB HTML, до 20 с, весь fetch до 90 с, до 3 redirects
только на разрешённые HTTPS-хосты; учётные данные/нестандартные порты запрещены.
HTML преобразуется в текст без JS, загрузки изображений и переходов по ссылкам.
Результат сохраняется только после успешной проверки всего pack.

Один вызов search_docs выдаёт до 2 KiB текста, первоначальная подборка — до 2 KiB;
ручной CLI-поиск — до 8 KiB. Общая история действий/число вызовов ограничены.
Полный pack не отправляется модели автоматически. Текст предложений не дублируется
в истории после передачи в списке proposals. Переполнение реального token context
отклоняется inference-адаптером, данные не усекаются молча ради обещания успеха.
Путь выбранного pack сохраняется в preferences; задания/ответы автоматически
не сохраняются. Отмену загрузки выполняет родительский GUI worker; сохранение
могло успеть завершиться до отмены — проверь выбранный путь.
